SIH PS-26168 ML Assets Directory
====================================
This directory contains the machine learning assets used by MlSpeedEstimator:

1. speed_estimator.tflite:
   The CNN+LSTM regression model exported to TensorFlow Lite format.
   Generated by running train_speed_model.py on the IO-VNBD dataset.
   
2. norm_stats.json:
   Feature mean and standard deviation for Z-score normalization of IMU inputs.
   Generated alongside speed_estimator.tflite during training.
